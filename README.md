# 📘 Bi-TAML: Мета-обучение для новостного холодного старта

## 🎯 Описание проекта
**Bi-TAML (Time-Aware Meta-Learning with News Cold-Start Extension)** – архитектура нейронной сети для решения задачи **новостного холодного старта** в рекомендательных системах на основе мета-обучения.

## 🧩 Архитектура Bi-TAML
### **Основные компоненты:**

1. **Модуль новостного холодного старта (NewsColdModel):**
   - Энкодер новостей (семантика)
   - Энкодер временных признаков
   - Эмбеддинги временных периодов

2. **Асимметричный механизм модуляции:**
   - Раздельная адаптация для пользователей и новостей

3. **Генератор мета-задач:**
   - Сбалансированное создание задач с отношением горячих/холодных новостей 2:1

## 🛠 Технологии
- Python 3.8+
- PyTorch
- pandas / numpy
- scikit-learn

## 📈 Метрики
- **Cold News AUC:** 0.9175
- **Hot News AUC:** 0.9071
- **Overall AUC:** 0.9223
- **Val F1-Score:** 0.84
